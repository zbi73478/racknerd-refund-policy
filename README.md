## 什么情况有机会被批，什么情况别浪费时间

既然是 case-by-case，就要搞清楚天平往哪边偏。两类情况的结局差别很大。

**有客观依据、值得开口的：**

1. **开通后立刻发现服务端故障**。VPS 起不来、IP 完全不通——刚付款几分钟就出问题，且几乎没有使用记录，这是最接近“合理退款”的情形。
2. **独立服务器超过 72 小时未交付**。条款承诺独服最长 72 小时开通，超时属于明确违约，要求退款站得住脚。
3. **机房持续故障、IP 完全不可用**这类明确的服务质量问题。

**大概率被拒的：** 服务正常跑了一段时间、单纯需求变了不想要了、带宽或资源已跑超。年付订单正常开通后，客服几乎没有理由批退款。

还要有心理预期：即使申请成立，客服最常给的方案往往不是原路退现，而是**转成账户余额、换机房位置或换更高配置补差价**。余额不能提现，但可以抵扣续费或加购，对打算长期用的人不算亏；只想要现金，就在工单里写清楚。

## 工单怎么提、取消怎么操作

退款和取消是两条流程，别混。

**争取退款**：在客户中心开 Billing 部门工单，附上证据——截图、ping/traceroute 记录、报错日志，越能证明是服务端问题越好。语气就事论事，别上来就威胁 chargeback，前面算过账了，$125–250 的管理费加上账户被暂停的风险，不划算。工单响应整体不慢，官方口径平均 20 分钟内回复，有用户计时 6 分钟就收到回复。

**取消服务**：客户中心 → Services → My Services → Request Cancellation，选 Immediate（立即）或 End of Billing Period（周期结束自动停）。这里有个最容易吃亏的细节：点了 Immediate 之后，系统 24 小时内终止服务，**数据立即删除且不可恢复**。误点了取消就马上再开工单，客服还有机会恢复；拖久了就真没了。Trustpilot 上两条最惨的差评，都是错过续费或误发起取消后整台服务器被清掉。

另一个方向是“怕忘续费”。到期后有宽限期，超期会暂停但数据不会立刻删，补付账单即可复机——有用户过期三天，付完半小时恢复。想彻底避免这事，可以在后台 Services 里用 Generate Renewal Invoice 提前生成下周期账单锁价，或者在 Billing → Add Funds 预充一笔余额（比如年付 $35.99 充 $36），账单生成后自动扣款。默认到期前 14 天会自动生成账单并邮件提醒，留意邮箱就行。

**RackNerd 有 30 天无理由退款吗？** 没有。官方知识库明确不提供 money back guarantee，条款只写个案处理。

**年付买了还能退吗？** 服务正常开通、没有技术故障的情况下，基本不能。特价套餐在条款层面明确不退款。

**IP 被墙能退吗？** 退款不一定，但可以开工单申请**换 IP 或迁移机房**——面板也支持自助换 IP。对多数人来说，换到能用的 IP 比退款更实际。

**误点立即取消怎么办？** 马上开工单说明误操作，动作快通常能恢复；数据一旦被清理就找不回来了。

**续费会涨价吗？** 不会。促销套餐是 recurring 锁价，写在服务协议里，续费按购买时价格走。如果确认是促销套餐但续费价异常变化，开工单反馈，属于系统异常。
